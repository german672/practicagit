# Introducción

Este manual explica, de forma práctica y para principiantes, cómo utilizar SQL Server Agent para crear, programar, ejecutar y comprobar un Job (trabajo automatizado).

## Entorno del manual

* **SQL Server:** 2025 Developer
* **SSMS:** 22
* **Instancia:** `localhost\SQLAGENT`

El resultado esperado es un Job funcional que permita comprobar su ejecución mediante el monitor de actividad, una tabla de bitácora, el archivo de respaldo y el historial.
