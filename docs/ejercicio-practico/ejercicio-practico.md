# Ejercicio completo

Este ejercicio reproduce el flujo del Manual de Uso FINAL.

## Resultado

Al finalizar se debe tener:

* Base `PracticaAgente`.
* Tabla `dbo.Bitacora`.
* Carpeta `C:\SQLBackups`.
* Job `Job_Mantenimiento_PracticaAgente`.
* Step de respaldo.
* Step de bitácora.
* Schedule diario.
* Evidencia en Activity Monitor.
* Registro en `Bitacora`.
* Archivo `PracticaAgente.bak`.
* Historial con ejecuciones exitosas.

## Orden

1. Preparar base y carpeta.
2. Crear Job.
3. Crear Steps.
4. Crear Schedule.
5. Ejecutar.
6. Verificar.
7. Revisar historial.
8. Configurar notificaciones y Proxy, si corresponde.
9. Revisar Error Log ante problemas.
