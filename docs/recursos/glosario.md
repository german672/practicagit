# Glosario

**Agent:** servicio que automatiza Jobs.

**Job:** trabajo automatizado.

**Job Step:** acción individual dentro del Job.

**Schedule:** programación del Job.

**Job History:** historial de ejecuciones.

**Activity Monitor:** monitor de actividad de Jobs.

**Bitacora:** tabla usada por la práctica para registrar una ejecución exitosa.

**Operator:** destinatario de notificaciones.

**Alert:** regla que reacciona a determinados eventos.

**Proxy:** mecanismo basado en Credential para determinados subsistemas de Job Steps.

**msdb:** base de sistema utilizada, entre otras funciones, por SQL Server Agent.
